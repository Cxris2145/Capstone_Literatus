# 📋 Product Backlog (Priorizado)

Este Backlog se gestiona bajo el modelo Scrumban. Las historias se consumen a través de "Prompts" enviados a los agentes de Inteligencia Artificial y pasan por un estricto flujo de auditoría.

| ID | Épica | Historia de Usuario / Funcionalidad Requerida | Prioridad | Estado |
|:---|:---|:---|:---:|:---|
| **US-01** | Autenticación | Como usuario, quiero registrarme e iniciar sesión (JWT) para guardar mi progreso y saldo. | Alta | Completado |
| **US-02** | Catálogo | Como lector, quiero ver un catálogo de libros clásicos para agregarlos a mi biblioteca. | Alta | Completado |
| **US-03** | Lector Core | Como lector, quiero leer el contenido por capítulos con temas visuales adaptables. | Alta | Completado |
| **US-04** | IA Avatares | Como lector, quiero chatear con los personajes del libro para resolver dudas de la trama. | Alta | Completado |
| **US-05** | TTS Audio | Como lector, quiero escuchar a los personajes hablar con voces realistas (Piper/Kokoro). | Media | Completado |
| **US-06** | Finanzas | Como usuario, quiero recargar "Tinta" usando Webpay Plus para seguir chateando. | Alta | Completado |
| **US-07** | Gamificación | Como usuario, quiero ganar experiencia, rachas y subir de nivel al completar capítulos. | Media | Completado |
| **US-08** | Comunidad | Como usuario, quiero unirme a Clubes de Lectura para debatir capítulos con compañeros. | Baja | En Progreso |
| **US-09** | Dashboard | Como administrador, quiero ver métricas de uso de IA y reportes de libros. | Baja | En Progreso |
